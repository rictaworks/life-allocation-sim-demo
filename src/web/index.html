アクセス解析の利用について

このサイトでは、利用状況を把握するためにアクセス解析（Google アナリティクス）を使うかどうかを選んでください。「許可」を選んだときだけ、Google アナリティクスを読み込み、利用状況を計測します。「拒否」を選ぶと、以後の表示では読み込みません。どちらを選んでも、このサイトの操作には影響しません。選択はこのブラウザに保存されます。
